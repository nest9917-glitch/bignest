BigNest — готовый статический сайт для Netlify

Публикация:
1. Откройте https://app.netlify.com/drop
2. Перетащите ZIP-архив bignest-netlify.zip или извлечённую папку bignest-site.
3. После публикации Netlify предоставит ссылку вида *.netlify.app.

Состав: index.html (страница), styles.css (оформление), script.js (меню), favicon.svg (иконка), assets/ (фотографии товаров и автора).

Важно:
- Для всех товарных карточек используется общая ссылка на магазин Ozon, потому что отдельные адреса товаров пока не предоставлены.
- Изображения Shorts подгружаются с YouTube, если сервис доступен в регионе посетителя. Видео открываются по клику на YouTube.
- Карточка брелоков содержит декоративную иллюстрацию, а не изображение реального товара.
- Логотип из присланного исходника не использован в шапке: он слишком тёмный на чёрном фоне. Пока создана контрастная текстовая версия BigNest.
- Сайт не заявляет о регистрации товарного знака.
